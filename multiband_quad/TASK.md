# TASK.md — 高次モードを含む波形の (h, h) を multibanding で速く計算する

（2026-10-17: オーナーの回答を反映して確定。追加要求「モード分解できず h+, h× しか得られない場合にも使える方法もつくる」を方法 B として組み込んだ。）

## 1. 目的

Morisaki (2021), PRD 104, 044062, arXiv:2104.07813（`notes/arXiv_2104.07813v2.pdf`、要約
`notes/paper_summary.md`）の multibanding では、尤度の 2 次項
$$(h,h) = \frac{4}{T}\sum_k \frac{|\tilde h(f_k)|^2}{S_k}$$
を、高次モード (HOM) を含む波形について **IFFT-FFT 法**（Sec. II.D.2, Eqs. 31–46）で計算している。
これは各バンドの粗い格子上の波形を IFFT → ゼロ詰め → FFT で 2 倍細かい格子へ補間し、折り畳んだ
PSD の重みと掛ける方法で、精度は良いが尤度評価ごとにバンド数だけ IFFT と FFT を要し、
波形生成に比べて無視できない時間がかかる。

本タスクのゴールは次の 2 つの計算法を確立し、数値実験で実証することである。

- **方法 A（モード別の波形が得られる場合）**: 同等以上の精度で、実行時に FFT を使わず、IFFT-FFT 法より大幅に速い方法。
- **方法 B（全波形 $h_+, h_\times$ しか得られない場合）**: モード分解を要さず、IFFT-FFT 法と同じ近似のもとで同じ精度を保ちつつ、
  FFT のコストを大幅に（目標 3 倍以上）減らす方法。

## 2. 提案手法（オーケストレーターの導出。`notes/method_idea.md` を参照）

- 波形をモード和 $h=\sum_A h_A$（$A=(l,m)$、非歳差）に分け、$|h|^2 = \sum_A |h_A|^2 + 2\,\mathrm{Re}\sum_{A>A'} h_A^* h_{A'}$ とする。
- 各順序付きモード対の積 $w^{(b)} h_A^* h_{A'}$ の「時間（ラグ）方向の台」は、
  定常位相近似より $\mathrm{lag}(f) = \tau_A(f) - \tau_{A'}(f)$ の値域で、遅いモードを先にとれば
  **片側**（$[0, \mathrm{lag}_{\max}]$）かつ $\mathrm{lag}_{\max} \lesssim \tau_{m_{\max}} < T^{(b)}$。
  （$t_c$ はラグに現れないので、論文の Eq. 51 に含まれる $t_c$ 事前分布幅 2.12 s は不要。）
- よって各対は **(d,h) と同じ粗い格子**の上で、対ごとに「時間ブロック」をそのラグ区間に合わせた
  事前計算済みの重み
  $$W_\kappa(B) = \frac{1}{\hat N}\sum_{m\in B} A_m^*\, e^{2\pi i m\kappa/\hat N},\qquad A_m=\sum_k \frac{e^{2\pi i k m/N^{(b)}}}{S_k}$$
  を使って $\sum_k a_k g_k = \sum_\kappa W_\kappa(B)\, g(\kappa/\hat T)$ と厳密に（台がブロック内なら）計算できる。
  論文の Eq. 45 は「全波形 $|h|^2$ に対称ブロック $2T^{(b)}$ を使った特殊例」であり、対称ブロックが
  必要だったのは $|h|^2$ 全体のラグ台が $[-T^{(b)}, T^{(b)}]$ と両側に広がるため。
- 実行時コストは $O(n_{\rm modes}^2 K_{\rm MB})$ の複素積和（バッチ化した 2 次形式）だけで FFT は不要。
  事前計算は PSD・窓・ブロックだけに依存する。
- トイ実験（`notes/orchestrator_toy.py`、`notes/method_idea.md` §6）では、IFFT-FFT 法と同じ
  相対誤差 ~2–4e-7 を粗い格子だけで達成した（線形補間法は 1.6e-6、ブロックの置き方を誤ると 4.4e-6）。
  誤差は $\sum_{m\notin B} A_m^* G_m$ で決まるので、PSD が滑らかだとブロックの置き方に鈍感になり、
  **狭い線スペクトルがあるとき**に置き方が効く。試験には線を含む PSD が必須。

要件: 波形モデルが各モード（または各 co-precessing モード）を任意周波数列で返せること。
IMRPhenomXHM（`SimIMRPhenomXHMFrequencySequenceOneMode`、環境に導入済み）がこれを満たす。
IFFT-FFT 法は全波形 $h$ しか要らないので、その点は IFFT-FFT 法の利点として記録する。

### 設計レビュー（2026-10-17）による修正点

敵対的レビュー 3 件（`notes/method_idea.md` §8）を反映した。(1) ラグ符号: 遅いモードを先にした順序付き対のブロックは正のラグ側。
(2) 窓は重みでなく積 $w^{(b)} h_A^* h_{A'}$ に付け、$a_k = 1/S_k$。(3) ラグ区間の下端は $\Lambda(f^{(b+1)}) \approx 0.5\,\Lambda_{\max}$ で 0 ではない。
$\tau_{lm}$ は $m$ だけで決まるので、バンドあたり 7 つのラグ・クラス（対角＋同じ $m$ の対、および $(m_A, m_{A'})$ の 6 組）に 1 本ずつ重みベクトルを持ち、
各クラスの区間 $[\Lambda_{\min} - L\sigma_{AA'}(f^{(b+1)}),\ \Lambda_{\max} + L\sigma_{AA'}(f_{\rm lo})]$（$\sigma_{AA'}^2 = |\tau'_A - \tau'_{A'}|$）の中心に長さ $M^{(b)}$ のブロックを置く。
(4) 区間は事前分布のチャープ質量範囲の両端（下端は $\mathcal{M}_{\max}$、上端は $\mathcal{M}_{\min}$）で取り、設定時に空き（slack）が負なら警告・停止する。
(5) 誤差は $\sum_{m\notin B} G_m (A^*_{\tilde m} - A^*_m)$（1 周期先の内容が $A_0$ に折り返る項が支配的）で診断する。
(6) **重要な注意**: 論文の Table I から、IFFT-FFT を含む波形以外の処理は HOM 尤度時間の 22〜25% なので、(h,h) を無料にしても全体の高速化は BNS で最大 ~1.3 倍、16 s 信号で ~1.1 倍。
さらに方法 A は毎回モード別波形を要し、lalsimulation の XHM では OneMode 呼び出し 6 回が偏波 1 回より遅い（1 万点で約 20 ms 対 12 ms）。
したがって反復 005 で「波形（全体／モード別）対 各法の (h,h) ステップ」の計時内訳を出し、方法 A を実用上の高速化として進めるかをオーナーが判断する。
方法 B0/B1 は全波形だけで動く。

### 方法 B0: 中心ブロック × 全波形（FFT もモード分解も不要、最も安い候補）

全波形の $w|h|^2$ に長さ $M^{(b)}$ の中心ブロックの重み（バンドあたり実数ベクトル 1 本、(d,h) と同じ粗い格子）を掛けるだけ。
ラグ台が $T^{(b)}/2$ を超える対の寄与は、PSD の核 $A_m$ が大きなラグで小さい（滑らかな PSD では 2 s で $A_0$ の $2\times10^{-3}$ 以下、線があっても同程度）ため抑えられる。
レビュアーのトイ（強い HOM、狭い線 8 本）では $\Delta\ln\Lambda \lesssim 5\times10^{-4}$（SNR 25）で、線形補間（最大 $10^{-2}$）より良く IFFT-FFT（$10^{-5}$ 以下）より悪い。実波形・実 PSD で検証する仮説。

### 方法 B1: ベースバンド化した IFFT-FFT（全波形のみで使える、IFFT-FFT と同精度）

全波形 $|h|^2$ のラグ台は両側 $[-\mathrm{lag}_{\max}, \mathrm{lag}_{\max}]$ なので半整数点の値は本質的に必要だが、
論文の実装は長さ $M^{(b)} \simeq 2 f^{(b+1)} T^{(b)}$（周波数 0 から）の IFFT と $2M^{(b)}$ の FFT を使っており、
バンド内の粗い点数 $K^{(b)} = K_e - K_s + 1 \simeq (f^{(b+1)} - f^{(b)} + \Delta f^{(b)}) T^{(b)}$ より数倍〜10 倍長い。
窓付き波形はバンド外で 0 なので、バンドの $K^{(b)}$ 点だけを長さ $K' \ge K^{(b)}$ の IFFT で「復調した」時系列にし
（時間方向の台は $T^{(b)}$ のまま）、半サンプルシフト $e^{-i\pi n/K'}$ を掛けて FFT すれば半整数点の値が厳密に（同じ時間制限の仮定で）得られる。
重みは $2T^{(b)}$ の対称ブロックの $W$（論文の $\tilde I_c$ と同じもの）をバンド内の点だけ使う。
さらに予測ラグ台が $T^{(b)}/2$ より短いバンド（短い高周波バンド）は半整数点が不要で FFT を省ける（$\hat N$ をバンドごとに $M$ か $2M$ から選ぶ）。
トイ実験（`notes/orchestrator_toy_methodB.py`）: 相対誤差 4.3e-7（論文の IFFT-FFT 2.2e-7 と同水準）、FFT 長 8192–16384 → 350–594、
(h,h) ステップ 1.61 ms → 0.26 ms（6 倍）。
